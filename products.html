AM Infra Batch Tool v1.0.0

A Civil 3D batch automation add-in — replaces repetitive, one-at-a-time workflows with real batch operations.

What it does

Replaces repetitive, one-at-a-time Civil 3D workflows with real batch operations — pick your inputs once, apply them across everything at once, and get back to the actual engineering.

  • Batch AlignmentsCreate alignments from multiple selected entities in one pass.
  • Batch Profile ViewsBuild profile views with sampled surfaces across many alignments at once.
  • Batch Add Surface ProfilesAdd surface profiles to existing profile views in bulk.
  • Batch Pipe RunsBuild pressure-network pipe runs along selected polylines, sized from a real part list.
  • Batch Crossing PipesDetect gravity/pressure pipes crossing a profile view's alignment, draw them in, and apply style overrides automatically.
  • Gravity AlignmentsPick the start and end of a gravity network's main run and auto-generate a Main alignment plus Branch alignments for every side path.
  • Gravity Profile ViewsGenerate a profile view for every Main/Branch alignment, with matching pipes and structures bound in automatically.
  • Rainbow PlanDraw color-coded utility offset polylines on each side of an alignment centerline, one per network per side.
  • Zoom to Profile ViewJump straight to the profile view(s) already showing a selected pipe run, fitting, or structure.
Compatibility: Civil 3D 2025 through 2027 Who it's for: Civil/Infrastructure engineers and designers running gravity or pressure pipe networks
