AM Infra Batch Tool

Civil 3D Batch Automation Add-in

v1.0.0

Replaces repetitive, one-at-a-time Civil 3D workflows with real batch operations — pick your inputs once, apply them across everything at once, and get back to the actual engineering.

  • Batch Alignments — create alignments from multiple selected entities in one pass
  • Batch Profile Views — build profile views with sampled surfaces across many alignments at once
  • Batch Add Surface Profiles — add surface profiles to existing profile views in bulk
  • Batch Pipe Runs — build pressure-network pipe runs along selected polylines, sized from a real part list
  • Batch Crossing Pipes — detect gravity/pressure pipes crossing a profile view's alignment, draw them in, and apply style overrides automatically
  • Gravity Alignments — auto-generate a Main alignment plus Branch alignments for every side path from a gravity network's topology
  • Gravity Profile Views — generate a profile view for every Main/Branch alignment, with matching pipes and structures bound in automatically
  • Rainbow Plan — draw color-coded utility offset polylines on each side of an alignment centerline, one per network per side
  • Zoom to Profile View — jump straight to the profile view(s) already showing a selected pipe run, fitting, or structure
Compatibility: Civil 3D 2025 through 2027 Who it's for: Civil/Infrastructure engineers and designers running gravity or pressure pipe networks
